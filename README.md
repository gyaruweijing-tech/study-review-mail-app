# study-review-mail（復習メルマガ）

> **このリポジトリは公開用のコピーです。** 本体は毎週、学習ノートと回答をリポジトリに書き戻す作りなので private にしています。
> ここにはコードだけを置き、学習ノート（`notes/`・`state.json`）は履歴ごと外しています。自動実行（GitHub Actions）も止めています。
> 送信元アドレスは Resend の見本用アドレスを使っていました（公開前の検査の都合で `example.com` に置き換えています）。

勉強したノートを、週1で「後輩キャラからの質問メール」として自分に届ける仕組み。
読むだけで終わらせず、質問に答えることで思い出す（答えは Issue で返す）。

- 配信：GitHub Actions（毎週木曜）→ Resend でメール送信
- 答え：Issue に書くと、Actions が受け取って記録する（リポジトリの持ち主が立てた Issue だけ処理する）
- 詳しい構成と経緯は [PROGRESS.md](./PROGRESS.md)
